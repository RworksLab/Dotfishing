# ドット釣り日和

スマホ向けのドット絵釣り＆コレクションゲームです。`index.html` 1ファイルで動きます（ブラウザで開くだけ）。

## 遊び方
- ホームから「釣りに出かける」で島マップの釣り場を選びます。
- ウキが沈んだらタップしてアワセ、魚がリングの中心に来たらタップしてゲージを貯めます。
- 釣った魚はクーラーから水族館へ。コインでショップの釣り具を強化し、新しい釣り場を解放します。

## 内容
- 釣り場5か所（港・沖合は準備中）、魚50種
- ゲーム内時間（朝・昼・夕・夜）と睡眠、時間帯で変わるBGMと環境音
- 竿・リール・糸 各5段階、依頼、着せ替え、5部屋の水族館

## アイコン
`icon/` に32×32ドットの「釣り上げられる金のコイ」を各サイズで置いています（1024 / 512 / 192 / 180 / 32 px、SVG）。
